# 11. Entregáveis

Cada equipe deverá entregar um arquivo compactado com a seguinte organização sugerida:

```
desafio_dados/
├── README.md
├── dados/
│   ├── brutos/
│   └── processados/
├── ingestao/
├── recomendacao/
├── sql/
│   ├── criar_banco.sql
│   └── consultas.sql
├── mongodb/
│   └── consultas.js
├── dashboard/
│   └── evidencias/
├── documentacao/
│   ├── modelo_de_dados.pdf
│   ├── arquitetura.pdf
│   ├── kpis.md
│   └── uso_da_ia.md
└── requirements.txt
```

**Entregáveis obrigatórios:**

1. código de ingestão;
2. arquivos de dados utilizados;
3. modelo conceitual e lógico;
4. scripts do PostgreSQL;
5. documentos e consultas do MongoDB;
6. implementação da busca vetorial;
7. implementação da recomendação;
8. exportação do dashboard do Superset;
9. documentação para instalação e execução;

# 12. Apresentação

Cada equipe deverá realizar uma apresentação de no **máximo** 10 minutos:

| Tempo     | Conteúdo                              |
| --------- | ------------------------------------- |
| 2 minutos | Problema e arquitetura.               |
| 3 minutos | Ingestão e armazenamento.             |
| 2 minutos | Busca vetorial e recomendação.        |
| 2 minutos | Dashboard e principais descobertas.   |
| 1 minuto  | Dificuldades, limitações e uso da IA. |

> **Verificação de aprendizagem:** qualquer integrante poderá ser solicitado a explicar uma parte da solução.
