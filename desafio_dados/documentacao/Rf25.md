# Relatório de Execução — RF25: Processamento Distribuído com Apache Beam

## 1. Visão Geral
Este documento registra a implementação e execução do pipeline de dados desenvolvido em **Apache Beam** (Python) para agregação de eventos de interação do projeto, contemplando execuções locais via **DirectRunner** e distribuídas via **SparkRunner**.

---

## 2. Regra de Negócio e Implementação
O pipeline executa as seguintes etapas de transformação:
1. **Ingestão:** Leitura dos dados de eventos no formato JSON (`dados/volume/interacoes.json`).
2. **Parsing & Desempacotamento:** Conversão de strings JSON para dicionários Python, aplicando `FlatMap` para desempacotar estruturas em lista.
3. **Mapeamento:** Seleção da chave `tipo_interacao` para formação de tuplas `(tipo_interacao, 1)`.
4. **Agregação:** Soma combinada por chave (`CombinePerKey(sum)`) para contabilização total por tipo de evento.
5. **Persistência em Parquet:** Mapeamento dos resultados agregados para um Schema PyArrow (`tipo_interacao`: String, `total`: Int64) e exportação em formato binário otimizado `.parquet`.

### 4. Conclusão

A implementação cumpre integralmente os requisitos do **RF25**:
- Mapeamento e agregação idempotente da regra de negócio em ambos os runtimes.
- Exportação nativa em formato Parquet utilizando tipagem forte PyArrow.
- Registro das métricas de volume e tempo nos dois ambientes de execução.
